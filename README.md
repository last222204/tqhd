# ☂️ 우산 T6

"나스닥 3배 우산 적립(T6)" 규칙을 매일 확인하고 기록하는 개인용 사이트입니다.
자동 매매는 하지 않습니다. 사이트가 신호를 알려주면, 증권사에서 직접 체결한 뒤 여기에 기록합니다.

> 이 사이트는 투자 조언 도구가 아니라, 내가 정한 규칙을 지키기 위한 기록 도구입니다.

---

## 켜는 법 (이것만 기억하세요)

1. 이 폴더(`우산_T6`)를 엽니다.
2. **`실행.bat`** 을 더블클릭합니다.
3. 잠시 뒤 브라우저가 열리고 사이트가 보입니다. (주소: http://localhost:8501)

- **처음 한 번은** 필요한 프로그램을 설치하느라 몇 분 걸립니다. 다음부터는 몇 초면 켜집니다.
- **끄려면** 검은 창(명령 프롬프트)을 닫으면 됩니다.
- 브라우저만 닫았다면 http://localhost:8501 을 다시 열면 됩니다.
- Windows 방화벽 창이 뜨면: 폰에서도 보려면 **"허용"**, PC 에서만 볼 거면 **"취소"**. (아래 '폰에서 보기' 참고)

### Python 이 없다는 오류가 나오면
https://www.python.org/downloads/ 에서 Python 을 설치합니다.
설치 첫 화면에서 **"Add python.exe to PATH"** 에 꼭 체크하세요. 그다음 `실행.bat` 을 다시 실행합니다.

## 시세는 언제 받나요?

- 사이트를 열면, 저장된 시세가 **마지막으로 마감한 미국 장**보다 오래됐을 때 자동으로 받습니다.
  - 겨울: 한국 시간 아침 06:00 이후, 여름(서머타임): 05:00 이후
- 언제든 위쪽의 **🔄 시세 새로고침** 버튼으로 다시 받을 수 있습니다.
- 받지 못하면 빨간 상자에 **"마지막으로 받은 날: ○월 ○일 종가"** 가 크게 뜹니다.
  그때 신호는 그 날짜 기준이라는 뜻입니다.
- **Yahoo 가 종가를 늦게 올릴 때** (몇 시간 늦는 날도 있음): 그날 정규장 **마지막 1분봉 값**으로
  "⏳ 잠정 종가"를 만들어 바로 신호를 냅니다. 공식 종가와 보통 몇 센트(0.01% 안팎) 차이입니다.
  화면에 노란 상자로 "잠정"이라고 표시되고, 공식 종가가 올라오면 자동으로 바뀝니다 (15분마다 다시 확인).
  잠정 종가로 판정했는데 경계선(±0.5%) 경고까지 떠 있다면, 공식 종가가 나온 뒤 한 번 더 확인하세요.

### 시뮬레이터 계산 방식
- **현실 모드 (기본)**: 매매는 신호 당일 종가. 원화는 그날 환율로 환전합니다. 양도차익은 원화 기준(환차익 포함, 이동평균 취득가)이고, 연 250만 원 공제 후 22%를 **다음 해 5월 마지막 거래일에 보유분을 팔아서** 냅니다(그 매도 차익도 과세). 배당·이자는 15.4%를 떼고 재투자합니다. 비용은 교체 편도 0.3%, 적립 매수 0.2%, 세금 납부용·마지막 매도 0.3%입니다.
- **검산 모드 (고급 설정)**: 코랩 백테스트 가정을 그대로 씁니다(환율 고정, 피난처 수익 전체에만 15.4%, 세금은 5월 첫 거래일에 평가액에서 차감 등).
  - 시작 월 141개(2010-03~2021-11) 검산 결과: 우산 평균 **2.351배**(코랩 2.35), 최악 1.208배(1.21). TQQQ 2.816배(2.82), QLD 2.152배(2.15), QQQ 1.554배(1.55). 자동 테스트로 매번 확인합니다.
- **상장 전 구간은 가상 데이터**: TQQQ(2010-02 전)·QLD(2006-06 전)는 QQQ×배수 − 단기금리 − 연 0.95%로 만듭니다. 결과 위에 경고가 뜹니다.
- **피난처**: SGOV(2020-06~) → BIL(2007-05~) → 단기금리 현금 순으로 이어 붙입니다.
- **환율**: 2003-12 이전은 FRED 공식 환율(DEXKOUS)을 씁니다.

### 신호 규칙 (코드에 이대로 들어 있음)
- QQQ **배당조정 종가**가 **50일선과 200일선 둘 다 아래** → ☂️ 피신 (화면 표기는 **현금(달러)**. 시뮬레이터·과거 기록 계산은 그대로 SGOV)
- 하나라도 위 (같아도 "위"로 봄) → ☀️ TQQQ
- 이동평균은 단순이동평균(SMA), 종가 기준
- 경고등은 정보일 뿐 신호를 바꾸지 않습니다. 손절·뉴스·확인 일수 같은 예외는 없습니다.

### 🦇 사냥 규칙 (피신 중에만, T6 판정과 별개)
- RSI2: 2일 RSI, 사용자 코랩 공식 그대로(재귀식). 배당조정 종가 기준.
- **진입**: T6 피신 중 + 마감 직전 실시간 RSI2 < 10 + QQQ < 피신 기준가(둘 다 아래 경계) → 마감 전 TQQQ 매수.
  - 사냥 기준가 = min(RSI2 10 경계 가격, 피신 기준가). 기준 위 1% 안이면 **사냥 대기**. 기준과 0.3% 안이면 "애매: 들어가지 않음".
- **종료** (먼저 오는 것): RSI2 > 50 / 5거래일째(그날 RSI2 < 10 이면 그날부터 다시 5일) / T6 맑음(TQQQ 그대로 보유).
- 확인 시각 = 미국 마감 10분 전 (서머타임·조기 폐장 반영). 미국 휴장일·주말엔 사냥 칸과 카운트다운이 안 나옵니다.
- 실시간 가격을 못 받으면 "실시간 없음"만 표시합니다(5일째 종료 안내는 그래도 나옴). "이번 사냥 건너뜀"을 누르면 그 회차 칸을 숨깁니다.
- 역산 검산: 1999-12-22~2026-11-13 매일 6,765일, 기준가로 판정한 결과와 RSI2 규칙 판정이 100% 일치.

## 폰에서 보기

1. PC 에서 `실행.bat` 을 켭니다. (PC 가 켜져 있고 이 창이 떠 있는 동안에만 폰에서 보입니다)
2. **처음 한 번**, Windows 방화벽 창이 뜨면 **"허용"** 을 누릅니다.
   ("공용 네트워크"에도 체크해야 할 수 있습니다)
3. 검은 창에 나오는 **External URL** 주소(예: `http://58.238.100.29:8501`)를 폰 브라우저에 입력합니다.
4. 폰 브라우저 메뉴에서 **"홈 화면에 추가"** 하면 앱처럼 쓸 수 있습니다.

> ⚠️ **지금은 인터넷 누구나 이 주소로 볼 수 있습니다.** (기록이 없는 지금 단계라 공개해도 된다고 정함)
> 2단계(매매 기록)를 만들 때 **비밀번호를 겁니다.**
> 새로고침 버튼은 아무나 연타하지 못하게 1분에 한 번만 눌리도록 해 두었습니다.
>
> - 인터넷 회사가 주소를 가끔 바꿀 수 있습니다. 폰에서 안 열리면 검은 창의 External URL 을 다시 확인하세요.
> - 다시 이 PC 에서만 열리게 하려면 `.streamlit\config.toml` 의 `address` 를 `"localhost"` 로 바꿉니다.
